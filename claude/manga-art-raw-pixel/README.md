# Marrowdeep — raw pixel manga stills

39 PNG stills, named by panel ID, plus an import manifest. Created with the built-in image generation tool. Staged in this repository folder for Claude to integrate later; the game's active artwork has not been changed by this upload. Start with `CLAUDE-INTEGRATION.md`.

The optional `op-7-wall` and all live gameplay / boss-fall panels are intentionally excluded. Keep those live in the game.

The sellsword keeps his face mostly hidden in a deep hood. Agathe has exactly one swaddled baby across her sequence. Both Choir panels contain exactly seven faces. Ending candle shots contain two candles.

Review the files in `gallery.html`. For later integration, copy the PNGs and manifest into `art/manga/`. The current game loader accepts a JSON array of filenames. No code integration has been performed here.

These are high-resolution PNG containers with deliberately coarse pixel artwork. The game's own crop and ink pipeline still runs on them. The art has been visually reviewed as stills; final caption overlap, slanted crop safety and re-dithering need an in-engine review before publishing.

Keep the AI-generated artwork disclosure when preparing the game's store submission.
