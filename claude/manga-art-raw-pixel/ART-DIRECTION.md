# Artwork direction

Approved treatment: raw coarse pixel manga, bone-white and near-black, jagged edges, broken highlights and sparse checkerboard dithering. Red only for specific story accents.

The first sellsword eyes portrait was rejected because it resembled Guts from Berserk. It has been removed from this deliverable folder. Do not reuse that face or propagate it to other scenes.

Sellsword design: face mostly hidden inside a deep hood; no visible spiky hair, heavy brow, or eye scar. Keep that hood silhouette in all later appearances.

Agathe continuity: exactly ONE swaddled baby throughout the portrait, cradle, and soul-light release. The cradle and release panels must use the same composition and contents; only the rising lights change. Previous versions with multiple bundles are rejected.

This source pack is staged separately for later integration. The upload does not change the active game artwork.
